# MyPatientHUB

MyPatientHUB is a responsive healthcare web application developed as a team project.

The project was first developed using HTML, CSS, and JavaScript, and later converted to React using Vite.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Git
- GitHub

## Project Structure

### Original Version
The original version was developed using HTML, CSS, and JavaScript.

It includes:
- Dashboard
- Find Doctor
- Find Clinic
- Login / Medical Clinic

### React Version
The React version is located in:

`MyPatientHub-React`

The interface was converted into reusable React components while keeping the original design and responsive layout.
